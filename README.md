# Deluxe — demonstration concept

Independent, unofficial website concept prepared for the studio owner to review. It is not presented as the studio's official website. Search indexing is disabled.

Buildless HTML, CSS and JavaScript. Publish this directory as a static site. No server, database or secret is required. The brief form only prepares a message; the visitor copies and sends it manually through Instagram.
